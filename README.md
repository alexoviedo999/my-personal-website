## Alejandro Oviedo — Personal Website

Live at: alexoviedo.info

My personal portfolio and project site, built with Next.js and React. It showcases my background, technical skills, and projects in agentic AI systems, along with some creative coding experiments.

### Pages

Home: landing page with intro and a 3D background animation. About: background and bio. Skills: technical skills overview. Projects: agentic AI projects, including a multi-agent customer support system, a delivery exception handling system, an EHR assistant, and a RAG system for enterprise document Q&A. Animations: generative art and 3D visualization experiments using Three.js and Vanta. Jerky Bot: an interactive chatbot. Contact: a contact form powered by Resend.

### Tech Stack

Built with Next.js for static site generation, React 19, and TypeScript, styled with Tailwind CSS. Background visualizations use Three.js and Vanta. The contact form is powered by Resend. Code quality is enforced with ESLint, Prettier, Husky, lint-staged, and Commitlint. Testing uses Jest, React Testing Library, and Cypress for end-to-end tests. The site is deployed on Vercel.

### Getting Started

Install dependencies and run the dev server with npm install and npm run dev, then open http://localhost:3000.

### Deployment

The site auto-deploys to Vercel on every push to main, and is served at alexoviedo.info.
